# 安全策略 / Security Policy

## 支持范围 / Supported versions

当前只维护最新的 `0.2.x` 版本。请先在 [Releases](https://github.com/IronMan-libingxue/ChatGPT-Web-Next/releases/latest) 确认最新版本。

Only the latest `0.2.x` release is currently maintained. Check [Releases](https://github.com/IronMan-libingxue/ChatGPT-Web-Next/releases/latest) before reporting a problem.

## 报告安全问题 / Reporting a vulnerability

请优先使用 GitHub 仓库的 **Security → Report a vulnerability** 私密报告入口。报告中可以包含版本、操作系统、复现步骤和经过脱敏的日志，但不要包含：

- 密码、验证码、Cookie 或令牌；
- 账号邮箱、真实 IP、设备 ID 或完整会话编号；
- 聊天正文、附件或完整网络请求；
- 能够访问他人账号或数据的内容。

Please use the repository's private **Security → Report a vulnerability** flow. A report may include the app version, operating system, reproduction steps, and redacted logs, but must not include credentials, cookies, tokens, account email addresses, real IP addresses, device IDs, full conversation identifiers, chat contents, attachments, complete network requests, or material that grants access to another person's account or data.

如果私密入口暂时不可用，请只提交不含敏感细节的公开问题，说明需要私下联系；不要先公开漏洞细节。

If private reporting is temporarily unavailable, open a public issue containing no sensitive details and ask for a private contact channel. Do not disclose the vulnerability first.
