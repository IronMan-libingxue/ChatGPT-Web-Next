# ChatGPT Web Next 0.2.1

## 中文

这是第一个完成 macOS 与 Windows 双平台人工验收的公开版本。

共同作者：[IronMan-libingxue](https://github.com/IronMan-libingxue)、[Jessica-yaoyao](https://github.com/Jessica-yaoyao)。

- 原生 Google 登录、两步验证、登录保持与账号切换；

- 下载管理、文件定位、刷新、缩放和五款内置图标；
- 项目或文件夹内状态识别与离线恢复；
- macOS 通用包、Windows x64 安装版和免安装版。

验收状态：macOS 完整功能验收通过；Windows 两种包已在多台实机、多个 Windows 版本上人工通过。当前 macOS 包未做 Apple 公证，Windows 包未使用商业代码签名。

## English

This is the first public release with completed user-run acceptance on both macOS and Windows.

Co-authors: [IronMan-libingxue](https://github.com/IronMan-libingxue) and [Jessica-yaoyao](https://github.com/Jessica-yaoyao).

Highlights:

- Native Google sign-in, two-step verification, persistent sign-in, and account switching.
- Isolated regular and incognito sessions.
- Egress IP, estimated location, time zone, local time, and ChatGPT response latency.
- A device-local IP and session-safety policy.
- Download management, file reveal, refresh, zoom, and five built-in icons.
- Project/folder state recognition and offline recovery.
- Universal macOS package plus Windows x64 setup and portable packages.

Acceptance status: full macOS functionality passed; both Windows packages passed manual testing on multiple physical machines and Windows versions. The current macOS package is not Apple-notarized, and the Windows packages are not commercially code-signed.
