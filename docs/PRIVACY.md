# 隐私与安全

ChatGPT Web Next 是本机桌面容器，不提供云端账号或自建后台。

## 本机保存

- 随机设备 ID 及其脱敏显示值；
- 会话安全状态、最后确认时间、剩余时长和匿名去重摘要；
- 页面显示的账号名称、项目名称、聊天名称与触发时间，最多 10 条、每条保留 7 天；
- 下载文件名、大小、状态、时间和本机保存路径，最近 50 条、每条保留 7 天；
- 图标选择、位置缓存及必要的界面偏好。

设备状态、检测记录、下载记录和偏好分开保存，并在系统支持时使用本机加密。写入采用完整替换，降低意外中断留下半份数据的风险。

## 不保存

- 密码、两步验证码、Cookie、令牌或登录凭据；
- 聊天正文、附件内容、完整请求、完整响应或完整会话编号；
- Google 或 ChatGPT 账号邮箱；
- 硬件序列号；
- 日常 Chrome、Edge、ChatGPT Web 或 ChatGPT Web2 的资料。

## 网络请求

- ChatGPT 网页及登录请求由其原始网站处理。
- 出口 IP 通过当前 ChatGPT 网页所属会话访问 `chatgpt.com/cdn-cgi/trace` 确认。
- 已确认 IP 可发送给 IPWho.is，以取得估计位置和时区。
- 本项目不上传设备记录、检测记录、下载记录或界面偏好。

## 清理行为

手动清缓存不会退出登录。手动清除登录及网页数据，或会话安全策略到期，会删除本应用中的 ChatGPT Cookie、缓存和网页存储；不会删除设备安全状态、检测记录、下载文件或图标选择。

下载记录中的“清空列表”只删除记录，不删除已经下载的文件。
